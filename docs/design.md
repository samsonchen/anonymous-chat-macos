# 畫面設計

這份文件記錄 `/design` 做出來的畫面設計結果，給階段一實作前端時使用。畫面有哪些元素、行為是什麼，以 `docs/architecture.md` 第 7 節為準。這份文件只補上「長什麼樣子」。

設計稿：https://claude.ai/artifact/B8ybj7YUPQGegagkM5d2tr（私人連結，只有建立者能開，要給別人看需從頁面的 Share 選單分享）

設計稿是靜態畫板，沒有互動。設計稿產生後沒有實際打開檢查過版面，實作時如果發現尺寸或排版有問題，以可用為準，並回頭更新這份文件。

## 2. 設計語彙（Design tokens）

實作時把這些值定義成 CSS 變數，畫面元件只引用變數，不直接寫色碼。

### 2.1 顏色

| 變數 | 淺色 | 深色 | 用途 |
|---|---|---|---|
| `--bg` | `#F5F5F5` | `#171315` | 頁面底色、訊息區底色、輸入框底色 |
| `--surface` | `#FFFFFF` | `#221D20` | 卡片、側邊欄、輸入區、手機版輸入代號頁底色 |
| `--border` | `#E3DEE0` | `#3A3236` | 邊線、分隔線 |
| `--text` | `#2B2326` | `#F2ECEE` | 主要文字 |
| `--muted` | `#6B6266` | `#B5AAAF` | 次要文字（時間、提示、說明） |
| `--primary` | `#9F0050` | `#C23A80` | 自己的訊息氣泡、送出鈕、進入鈕、自己的頭像 |
| `--header` | `#9F0050` | `#7A003D` | 聊天室頂端列 |
| `--accent` | `#FFE66F` | `#FFE66F` | 連線橫條底色、頂端列上的在線小圓點 |
| `--accent-soft` | `#FFF6C9` | `#3D3300` | 回來提示的底色 |
| `--accent-text` | `#4A3B00` | `#FFE66F` | 黃色底上的文字 |
| `--danger` | `#B3261E` | `#FF8A80` | 錯誤文字、錯誤邊線、超過字數 |
| `--danger-soft` | `#FDECEA` | `#3A1D1B` | 錯誤提示、無法連線提示的底色 |
| `--warn` | `#9A4A00` | `#FFB866` | 字數接近上限（450 字以上） |
| `--dis-bg` | `#E6E1E3` | `#332C30` | 不能按的按鈕、鎖住的輸入框底色 |
| `--dis-text` | `#6B6266` | `#B5AAAF` | 不能按的按鈕文字 |
| `--self-name` | `#9F0050` | `#F29BC4` | 自己的代號文字顏色 |
| `--other` | `#FFFFFF` | `#2C2629` | 別人的訊息氣泡底色 |
| `--tint` | `#F9E8F1` | `#3A1F2E` | 線上名單中自己那一列的底色 |
| `--scrim` | `rgba(30,20,25,0.45)` | `rgba(0,0,0,0.6)` | 手機版名單展開時，下方的遮罩 |

頂端列與自己的氣泡上的文字固定是白色 `#FFFFFF`。

### 2.2 代號顏色

每個代號依名字固定對應一種顏色（同一個名字永遠同色）。做法：把代號（轉小寫後）算出一個數字，對 8 取餘數，選第幾個顏色。自己的代號不使用這組顏色，用 `--self-name`。

| 序號 | 淺色 | 深色 |
|---|---|---|
| 0 | `#0B6E99` | `#5CC0E8` |
| 1 | `#6D45B0` | `#B79CF0` |
| 2 | `#9A4A00` | `#F0B15C` |
| 3 | `#1E7A4C` | `#6FD39B` |
| 4 | `#B23B0C` | `#FF9C6B` |
| 5 | `#4B4BC4` | `#A5A5FF` |
| 6 | `#A1215B` | `#F29BC4` |
| 7 | `#5B6470` | `#B8BFC9` |

線上名單的頭像圓圈用同一組顏色當底色，圓圈裡放代號的第一個字。淺色模式頭像文字白色，深色模式用 `#171315`。

### 2.3 字型

- 字體：Noto Sans TC（Google Fonts，字重 400、500、700），後備 PingFang TC、system-ui。
- 輸入框、按鈕、文字區塊都要繼承這個字體（瀏覽器預設不會繼承）。

| 用途 | 大小 | 字重 |
|---|---|---|
| 輸入代號頁大標題 | 電腦 28px、手機 26px | 700 |
| 輸入代號頁說明 | 16px | 400，行高 1.5 |
| 頂端列標題「匿名聊天室」 | 電腦 18px、手機 16px | 700 |
| 頂端列副標 | 12px | 400 |
| 訊息內容 | 電腦 16px、手機 15px | 400，行高 1.5 |
| 代號標籤（訊息上方） | 13px | 500 |
| 時間、字數 | 12px | 400 |
| 進出提示 | 13px | 400 |
| 保留說明、日期 | 12px | 400 |
| 輸入框文字 | 16px | 400 |
| 輸入代號頁輸入框 | 17px | 400 |
| 按鈕 | 14～16px | 500 或 700 |

輸入框文字至少 16px，避免 iPhone Safari 在輸入時自動放大畫面。

### 2.4 圓角、尺寸

- 訊息氣泡圓角 18px，內距 10px 14px。氣泡最大寬度：電腦 62%、手機 80%。
- 輸入框外框圓角 16px，邊線 1.5px。
- 輸入代號的輸入框與按鈕高度 52px，圓角 14px。
- 輸入代號卡片（電腦）寬 460px，圓角 28px，內距 44px 40px。
- 頂端列高度：電腦 64px、手機 56px。
- 電腦側邊欄寬 288px。
- 所有可按的東西（按鈕、名單列）最小高度 44px。
- 送出鈕是 48px 的圓形。
- 頭像：側邊欄與名單 36px 圓形。

### 2.5 圖示

全部是描邊線條圖示（stroke 2px、圓頭圓角），顏色跟隨文字（`currentColor`）。不使用 emoji 當圖示。

| 圖示 | 用在哪裡 |
|---|---|
| 對話框 | 聊天室標誌（頂端列、輸入代號頁） |
| 紙飛機 | 送出鈕 |
| 向下箭頭 / 向上箭頭（V 形） | 手機「N 人在線」旁，展開 / 收起 |
| 向下箭頭（箭桿） | 「有新訊息」按鈕 |
| 出口 | 離開按鈕 |
| 驚嘆號圓圈 | 錯誤提示 |
| 資訊圓圈 | 回來提示 |
| 斷線（Wi-Fi 打叉） | 無法連線提示 |
| 轉圈（四分之一圓弧） | 連線橫條、進入中 |

## 3. 畫面 A：輸入代號

### 版面

- **電腦**：整頁底色 `--bg`，卡片置中，卡片底色 `--surface`、有邊線。
- **手機**：整頁底色 `--surface`，沒有卡片，內容垂直置中，左右內距 24px。

卡片（或手機整頁）由上而下：

1. 標誌：64px 圓角方塊（圓角 20px），底色 `--primary`，中間白色對話框圖示。
2. 標題「匿名聊天室」。
3. 說明兩行：「不用登入，取個代號就能加入。」「所有人都在同一個聊天室裡。」
4. 提示區（只有特殊狀態才出現，見下）。
5. 標籤「你的代號」。
6. 輸入框，右側顯示字數「N / 12」。
7. 錯誤訊息（只有錯誤時出現）。
8. 格式說明：「1～12 個字，中英文、數字、emoji 都可以。」
9. 「進入聊天室」按鈕，滿版寬度。

各區塊之間間距 16px，標誌到按鈕之間的大區塊間距 28px。

### 狀態

| 狀態 | 輸入框 | 提示區或錯誤訊息 | 按鈕 |
|---|---|---|---|
| 正常 | 預填上次的代號，邊線 `--border` | 無 | 可按（`--primary`） |
| 代號已被使用 | 邊線 `--danger` | 錯誤訊息：「這個代號已經有人用了，請換一個」（紅色、驚嘆號圖示） | 可按 |
| 格式不符（太長） | 邊線 `--danger`，字數變紅粗體「13 / 12」 | 錯誤訊息：「代號最多 12 個字」 | 不能按（`--dis-bg`） |
| 進入中 | 鎖住、底色 `--dis-bg` | 無 | 鎖住，轉圈圖示加「進入中…」，底色維持 `--primary` 但降低不透明度（0.8） |
| 斷線太久被送回 | 預填代號 | 提示區（黃底、資訊圖示）：「連線中斷太久，代號已被他人使用，請重新輸入。」 | 可按 |
| 無法連線 | 鎖住 | 提示區（紅底、斷線圖示）：「目前無法連線，請稍後再試。」 | 不能按 |

格式不符還包括：全空白、含看不見的字元（架構文件第 9.1 節）。這兩種的訊息文字設計稿沒有畫出來，實作時比照「代號太長」的樣式，建議文字：「代號不能是空白，也不能含看不見的字元」。

輸入框取得焦點時，邊線改用 `--primary`（設計稿未畫，實作時加上）。

## 4. 畫面 B：聊天室

### 4.1 電腦版版面

```
┌──────────────────────────────────────────────────────────────┐
│ 頂端列 64px：標誌 標題/副標 ········ [目前 5 人在線] [離開]  │
├────────────────────────────────────────────┬─────────────────┤
│ 連線橫條（斷線時才有，40px）              │ 側邊欄 288px    │
│                                            │ 線上成員  5 人  │
│ 訊息區（捲動）                             │ ○ 小明（你）   │
│                                            │ ○ 小華         │
│                       [↓ 有新訊息]         │ ○ Amy …        │
├────────────────────────────────────────────┤                 │
│ 輸入區：[文字框 + 字數] (送出)             │                 │
│ Enter 送出　Shift + Enter 換行             │                 │
└────────────────────────────────────────────┴─────────────────┘
```

連線橫條在設計稿只畫在手機版，電腦版出現時放在訊息區上方，橫跨訊息區與輸入區那一欄（不蓋住側邊欄）。

### 4.2 手機版版面

由上而下：頂端列 56px、連線橫條（斷線時）、訊息區、輸入區。沒有側邊欄，線上名單從頂端列展開。

### 4.3 頂端列

- 底色 `--header`，文字白色。
- 左：標誌（白色圓角方塊、酒紅色圖示）、標題「匿名聊天室」。電腦版標題下方有副標「不用登入，用代號就能聊」，手機版沒有副標。
- 右：
  - 在線人數按鈕：半透明白底（`rgba(255,255,255,0.18)`）的膠囊，左邊有黃色（`--accent`）小圓點。電腦版顯示「目前 5 人在線」，只是資訊，不能按；手機版顯示「5 人在線」加向下箭頭，點了展開名單。
  - 離開按鈕：透明底、白色邊線、出口圖示加「離開」。

### 4.4 訊息區

- 底色 `--bg`。內容由下往上排（訊息少的時候貼著輸入區）。
- 電腦版左右內距 32px，手機 14px。
- 最上方：保留說明「只保留最近的 200 則訊息」，置中、12px、`--muted`。
- **日期分隔線**：日期文字置中，左右各一條 1px 的 `--border` 線。例：「9月30日」「10月1日」。
- **進出提示**：置中一行 `--muted` 小字，例：「小華 加入了聊天室」「阿傑 離開了聊天室」。沒有背景框。
- **一般訊息**：
  - 別人的靠左：氣泡底色 `--other`、1px `--border` 邊線、文字 `--text`。
  - 自己的靠右：氣泡底色 `--primary`，無邊線，白色文字。
  - 同一個人連續發言為一組：只有第一則上方顯示代號（顏色見 2.2；自己用 `--self-name`），組與組之間隔 10px，同組訊息之間隔 4px。
  - 每則氣泡旁邊顯示時間「時:分」（12px、`--muted`）：別人的在氣泡右側，自己的在氣泡左側，對齊氣泡底部。
- **「有新訊息」按鈕**：浮在訊息區底部中央（離底 14px），膠囊形，`--primary` 底、白字、向下箭頭圖示，有陰影。只有使用者往上捲時才出現，點了捲到最底並消失。

### 4.5 輸入區

- 底色 `--surface`，上緣有 1px `--border` 線。內距：電腦 16px 24px，手機 12px 16px。
- 文字框：外框圓角 16px、1.5px 邊線、底色 `--bg`。裡面是文字輸入區，右下角是字數「N / 500」。電腦版文字區高度 2 行、手機版 1 行起（輸入多行時再長高，高度上限實作時決定）。
- 右邊：送出鈕（48px 圓形）。
- 電腦版輸入區底下一行小字：「Enter 送出　Shift + Enter 換行」。手機版沒有。
- 無障礙：文字框要有隱藏的標籤「訊息內容」，送出鈕有 `aria-label`「傳送訊息」。

| 狀態 | 文字框 | 字數 | 送出鈕 |
|---|---|---|---|
| 空白 | 顯示佔位文字「輸入訊息…」 | `--muted`，「0 / 500」 | 不能按 |
| 有內容 | 正常 | `--muted` | 可按（`--primary`） |
| 450 字以上 | 正常 | `--warn` 粗體 | 可按 |
| 超過 500 字 | 外框 `--danger` | `--danger` 粗體 | 不能按 |
| 斷線 | 鎖住、底色 `--dis-bg`，**保留已打的字** | 維持 | 不能按 |

### 4.6 線上名單

- **電腦**：右側欄一直顯示。標題列「線上成員」，右邊「5 人」。底下一列一個人：頭像（36px 圓、代號第一個字）加代號。自己那一列有 `--tint` 底色，名字後面加「（你）」（`--muted`）。列高至少 44px，圓角 12px。
- **手機**：點頂端列的「N 人在線」，名單從頂端列下方展開（底色 `--surface`、下方圓角 22px、有陰影）。內容同電腦版，最下方有「收起名單」按鈕（向上箭頭）。名單以下的畫面蓋一層 `--scrim`。點「收起名單」、「N 人在線」或遮罩都會關閉。

### 4.7 連線橫條

- 高度 40px，底色 `--accent`，文字 `#4A3B00`（深色模式設計稿沿用同一組顏色，如果覺得太亮可改用 `--accent-soft` 加 `--accent-text`）。
- 轉圈圖示加「連線中斷，重新連線中…」，置中，14px，字重 500。
- 位置在頂端列正下方。
- 標記為 `role="status"`。

## 6. 實作時要注意的地方

- 設計稿中的訊息內容、代號（小明、小華、Amy、柚子、Leo、阿傑）都是示範用，不是要放進程式的資料。階段一的示範假成員，代號要照架構文件寫成「示範-」開頭。
- 設計稿的訊息區是「靜態排好」的。實際的捲動行為（在底部時自動捲到最新、往上看時顯示「有新訊息」按鈕）以架構文件第 7 節為準。
